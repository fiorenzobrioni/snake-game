# 🐍 Snake 3.1.0 - the release build becomes real

Nothing in the game changes: this release changes **the APK you download**. Same
Snake as 3.0.0 inside; outside, for the first time, a proper release build -
R8-minified and signed with the project's release key instead of the public debug
keystore. versionCode 31, versionName 3.1.0.

## Why

Previous releases shipped the debug APK, signed with the shared keystore committed
in the repository. That keystore is public, password included: anyone can sign an
APK with the same key, and Android treats it as a legitimate update, installable
over the app of whoever downloaded it from here. No abuse was ever observed, but a
flaw by construction does not wait to be observed. The release key lives outside
the repository and reaches the build only through CI secrets. For the same reason
the **APKs of past releases were removed**: their notes and tags remain, but a
forgeable artifact should not be anyone's entry point.

## Installing

The release build drops the `.debug` application id suffix, so this version
installs **alongside** a debug-signed 3.0.0 rather than over it - a one-off fresh
install, same as the 2.0.0 → 3.0.0 id move. Progress does not transfer; uninstall
the old copy whenever you like. From 3.1.0 on, every release updates in place.

1. Download the APK from the "Assets" section below.
2. Open it on the phone (Android 13 or newer): Android asks to allow installs from
   this source, once.

## Under the hood

- The APK is minified and shrunk by R8: smaller, not debuggable, no development
  instrumentation. CI now builds the minified APK on every push, so R8 stays
  exercised instead of appearing for the first time on a release.
- The release itself is built by a workflow from the tag: tests and lint first, the
  signed APK and its R8 mapping attached, these notes (versioned in
  `docs/release-notes/`) as the body. No hand-assembled artifacts.
