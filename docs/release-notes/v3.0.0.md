## Auto-growth

The snake now **grows on its own** as a run goes on. Length became a resource
with a cost: food was rebalanced around the growth clock, a **risk bonus**
scales your score with the share of the board you occupy, and the **Shed**
ability cuts 35% of your tail, tail-first, and pays you for it.

Playing safe is no longer a strategy. You have to keep eating, and eat the
right pieces.

### What else is new

- 🌊 **Endless waves** - an Endless run plays undisturbed for 45 seconds, then a
  named event sweeps the board for 12 seconds, hail included. Each wave is
  announced and counts down in the HUD, in its own colour.
- 🏅 **Achievements are a career ladder** - ranks instead of one flat list.
  Skin unlocks are gone: every skin is simply free.
- 📖 **In-app Guide** - a rules reference on the main menu, in collapsed
  chapters. Every number in it is read from the game's own constants, so it
  cannot drift out of date when the balance is tuned.
- 🧭 **Rebuilt first-run tour** - six skippable cards covering the goal, the
  food language, length as a resource, power-ups and hazards, the four modes
  and the daily loop. Re-openable any time from Settings.
- ⚙️ **One-screen Custom Game setup** - no more scrolling to configure a run.
- 👻 **Ghost replay** of your best run, off by default, toggleable in Settings.
- 🎨 **Pixel skin redrawn** as 5x5 sprite art.

### ⚠️ This release needs a clean install

The app changed identity. Android treats that as a different app, so 3.0.0
installs **alongside** 2.0.0 instead of updating it. Uninstall the old version
by hand, and note that its highscores go with it.

This is a one-off. From 3.0.0 onwards every release is signed with the same
key and updates in place, keeping your scores and settings.

### Install

Download `snake-3.0.0-debug.apk` below and open it on your phone (you will need
to allow installation from unknown sources). Requires **Android 13** or newer.

The APK is debug-signed. A Google Play track with a release-signed AAB is a
later phase.
