# 🐍 Snake 1.0.0 - first release

Snake leaves beta! This is the first native Android release (Kotlin + Jetpack Compose).

## Highlights
- **Three modes** - Endless (accelerating), Time Attack (120s, with ±time pieces)
  and a 15-level **Campaign** (lives, shaped boards, moving-wall gates & teleport portals).
- **Power-ups & hazards** - Lightning, Star, Freeze, Snail, Jackpot, plus Earthquake
  and Explosion, with caution rings and a danger telegraph.
- **Six skins** (two free, four unlockable), Light/Dark/System themes, and a CRT filter.
- **Depth & retention** - 30 achievements, rotating Daily Missions, a date-seeded
  Daily Challenge with streaks & weekly history, Random Challenge, and a Records table.
- **Feel** - smooth inter-tick motion, particles, AGSL shaders, music & SFX with
  independent volumes, haptics, and a Reduce-motion accessibility toggle.
- **First-run tutorial**, three control schemes (swipe / wedge dial / tap-to-turn),
  and an in-app Credits screen.

## Install
The attached APK is a **debug build** (debug-signed, applicationId
`com.brioni.snake.debug`, not R8-minified) - perfect for sideloading. On your device,
allow "install unknown apps" for your browser/file manager, then open the APK.

- `snake-1.0.0-debug.apk` - install this directly.
- `snake-1.0.0.zip` - the same APK bundled with `README.md` and `LICENSE`.
